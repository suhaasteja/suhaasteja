## What I Build

I design and ship **AI agent systems** — from multi-tier memory architectures to adversarial evaluation pipelines. My work focuses on making LLM agents more reliable, observable, and production-ready.

- **Agent Infrastructure** — [SageMem](https://github.com/suhaasteja/SageMem): GPU-inspired L1/L2/L3/DRAM memory hierarchy for multi-agent systems using Redis + pgvector
- **Agent Observability** — [playback](https://github.com/suhaasteja/playback): Session log visualizer that turns raw JSONL agent traces into step-by-step timelines
- **Adversarial Evaluation** — [gauntlet](https://github.com/suhaasteja/gauntlet): CLI tool spawning 6 AI personas to red-team PRDs and codebases for weaknesses
- **Developer Tooling** — [claude-deck](https://github.com/suhaasteja/claude-deck): Claude Code statusline showing context %, model, API usage, and Spotify track
- **Applied AI** — [NFL-contract-coach](https://github.com/suhaasteja/NFL-contract-coach): AI platform reviewing sports contracts for predatory clauses across 10 risk categories
- **Embodied AI** — [reachy-rx](https://github.com/suhaasteja/reachy-rx): Pharmacist robot on Reachy-mini (3rd place, Seeed Studio hackathon)
